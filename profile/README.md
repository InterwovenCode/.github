# InterwovenCode

> 将实用软件融入日常，让技术连接彼此。

InterwovenCode 是一个以促进人与人之间的联系、赋予软件人文关怀为目标的开发组织。我们致力于打造实用的桌面工具、创意工具和 Unity 扩展。

## 精选项目

- **[ScreenPinKit](https://github.com/InterwovenCode/ScreenPinKit)** — 轻量级截图与屏幕标注工具，灵感来自 Snipaste、Excalidraw 和 ShareX。
  - [扩展插件](https://github.com/InterwovenCode/ScreenPinKit_Extensions) · [插件示例](https://github.com/InterwovenCode/ScreenPinKit-Plugin-Examples)
- **Unity 工具** — [RectTransform 对齐扩展](https://github.com/InterwovenCode/UnityRectTransformAlignExtension) 与 [Unity 多语言插件](https://github.com/InterwovenCode/UnityPluginLocalization)。
- **桌面小工具与实验项目** — [桌面时钟](https://github.com/InterwovenCode/desktop_clock)、[鼠标点击特效](https://github.com/InterwovenCode/mouse_click_effect) 和 [桌面特效](https://github.com/InterwovenCode/desktop_effect)。
