# InterwovenCode

> Weaving useful software into everyday workflows.

InterwovenCode is a development organization focused on fostering human connections and bringing a humanistic spirit to software. We build practical desktop utilities, creative tools, and Unity extensions.

## Featured projects

- **[ScreenPinKit](https://github.com/InterwovenCode/ScreenPinKit)** — a lightweight screenshot and annotation tool inspired by Snipaste, Excalidraw, and ShareX.
  - [Extensions](https://github.com/InterwovenCode/ScreenPinKit_Extensions) · [Plugin examples](https://github.com/InterwovenCode/ScreenPinKit-Plugin-Examples)
- **Unity tools** — [RectTransform Align Extension](https://github.com/InterwovenCode/UnityRectTransformAlignExtension) and [UnityPluginLocalization](https://github.com/InterwovenCode/UnityPluginLocalization).
- **Desktop experiments** — [desktop_clock](https://github.com/InterwovenCode/desktop_clock), [mouse_click_effect](https://github.com/InterwovenCode/mouse_click_effect), and [desktop_effect](https://github.com/InterwovenCode/desktop_effect).
